# Batches

Een batch groepeert drie tot vijf samenhangende Stories op één branch. Iedere Story krijgt een eigen lokale commit; push, PR en merge volgen pas na de laatste Story en volledige batchvalidatie.

Gebruik [BATCH_TEMPLATE.md](BATCH_TEMPLATE.md) als batchdossier en [de compacte batchtemplate](../templates/BATCH.md) voor opdrachten. Volg de [Codex Execution Rules](../CODEX_EXECUTION_RULES.md) en review tegen de [Architecture Guard](../ARCHITECTURE_GUARD.md).
