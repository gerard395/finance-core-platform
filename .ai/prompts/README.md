# Prompts

Deze map is gereserveerd voor geteste, herbruikbare prompts voor terugkerende projectactiviteiten, zoals refinement, review of documentatiecontrole. Projectregels blijven leidend; een prompt mag ze niet vervangen of versoepelen.

## Vereiste opbouw

Een prompt vermeldt minimaal:

- doel en beoogde gebruiker;
- benodigde invoer en toegestane repositoryscope;
- relevante contextdocumenten;
- verwacht uitvoerformaat;
- verplichte controles en stopvoorwaarden;
- versiedatum en eigenaar.

## Veilig gebruik

- neem geen geheimen, persoonsgegevens of productiegegevens op;
- vraag om verificatie op basis van repositorybronnen;
- laat onduidelijkheden, aannames en niet-uitgevoerde controles rapporteren;
- beoordeel gegenereerde output altijd via de normale reviewworkflow.

Er zijn momenteel geen projectspecifieke prompts vastgesteld.
