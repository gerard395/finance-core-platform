# I1-003A – Add Money sign queries

## Story ID

I1-003A

## Milestone

M5 – Integrated Financial Flow

## Epic

I1 – Prove the System

## Doel

Het capabilityneutrale Money value object uitbreiden met veilige semantische tekenqueries voor Application-orchestratie.

## Scope

- `Money::isPositive(): bool`.
- `Money::isNegative(): bool`.
- Tests voor positieve, negatieve en canoniek genormaliseerde bedragen.

## Invarianten

- Nul is niet positief en niet negatief.
- Een positief bedrag retourneert alleen true voor `isPositive()`.
- Een negatief bedrag retourneert alleen true voor `isNegative()`.
- Beide queries lezen uitsluitend de bestaande canonieke representatie en muteren Money niet.
- Er worden geen floats gebruikt.
- Bestaande `amount()`, `equals()`, `add()`, `absolute()` en `multiply()` blijven ongewijzigd.
- Shared Finance krijgt geen Banking-, Sales-, Purchasing-, Fiscal- of Accounting-dependency.
