# S2-001 – User Domain

## Doel

De eerste frameworkonafhankelijke Identity Aggregate Root introduceren voor gebruikersidentiteit, contactadres en status.

## Architectuurbesluiten

- `User` is de Aggregate Root.
- `UserId`, `DisplayName` en `EmailAddress` zijn immutable value objects.
- `UserId` composeert de gedeelde `Uuid` zonder validatie of generatie toe te voegen.
- E-mailadressen worden syntactisch gevalideerd en naar lowercase genormaliseerd.
- Uniekheid van e-mailadressen vereist externe gegevens en valt buiten het value object.
- Het Domain kent geen Laravel, Illuminate, Eloquent, database, repositories of infrastructuur.

## Acceptatiecriteria

- User heeft een onveranderlijke domeinspecifieke identiteit.
- DisplayName bevat 2 tot en met 255 Unicode-tekens zonder omliggende whitespace.
- EmailAddress accepteert uitsluitend een geldig adres en normaliseert dit naar lowercase.
- User ondersteunt expliciete naams-, e-mail- en statuswijzigingen.
- Activeren en deactiveren zijn idempotent.
- Alle code blijft framework- en infrastructuuronafhankelijk.

## Tests

Unit tests dekken identiteit, displaynaam, e-mailadres, constructie, mutaties en statusovergangen.
