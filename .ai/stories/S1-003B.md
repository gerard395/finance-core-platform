# S1-003B – Currency Value Object

## Story ID

S1-003B

## Epic

Shared Domain Foundation

## Status

In Progress

## Doel

Een frameworkonafhankelijk en immutable `Currency` value object introduceren voor functionele basisvaluta en transactievaluta.

## Architectuurbesluiten

- `Currency` is een `final readonly class` en gebruikt strict types.
- Alleen native PHP is toegestaan.
- Het type valideert uitsluitend de vorm van een aangeleverde code.
- Geldige codes worden naar hoofdletters genormaliseerd zonder whitespace te verwijderen.
- Bedragen, symbolen, koersen, catalogi en infrastructuur vallen buiten deze story.

## Bestanden

- `app/Domain/Shared/Finance/Currency.php`
- `app/Domain/Shared/Finance/README.md`
- `tests/Unit/Domain/Shared/Finance/CurrencyTest.php`
- `.ai/stories/S1-003B.md`

## Acceptatiecriteria

- De code bestaat uit exact drie ASCII-letters.
- Lowercase en mixed-case invoer worden naar uppercase genormaliseerd.
- Whitespace en alle overige ongeldige invoer worden met `InvalidArgumentException` geweigerd.
- `code()`, `toString()` en `__toString()` geven de canonieke code.
- Gelijkheid wordt op basis van de canonieke code bepaald.
- Het type is immutable en heeft geen framework- of infrastructuurafhankelijkheden.
- Er is geen volledige valutalijst hardcoded.

## Tests

Unit tests dekken geldige casing, normalisatie, gelijkheid, ongelijkheid, stringrepresentatie en afwijzing van verkeerde lengte, cijfers, symbolen, whitespace, lege invoer en niet-ASCII letters.
