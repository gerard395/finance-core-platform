# S1-006 – Administration Aggregate

## Story ID

S1-006

## Epic

Administration Domain

## Status

In Progress

## Doel

De eerste frameworkonafhankelijke Aggregate Root introduceren voor een zelfstandige administratieve eenheid.

## Afhankelijkheden

- S1-003B levert het gedeelde `Currency` value object.
- S1-005 levert het domeinspecifieke `AdministrationId` value object.

## Architectuurbesluiten

- `Administration` is een kleine final Aggregate Root zonder framework- of infrastructuurafhankelijkheden.
- Identiteit en code zijn onveranderlijk.
- Naam, omschrijving, basisvaluta en status veranderen uitsluitend via expliciet domeingedrag.
- Value objects bewaken code- en naaminvarianten.
- Organisation en boekhoudkundige beperkingen vallen buiten deze story.

## Acceptatiecriteria

- De Aggregate Root exposeert uitsluitend de afgesproken lees-API en domeingedragingen.
- Identiteit en code hebben geen mutatiemethode.
- Code, naam en omschrijving voldoen aan hun vastgelegde invarianten.
- Statuswijzigingen zijn expliciet en idempotent.
- De basisvaluta kan via expliciet domeingedrag worden gewijzigd.
- De Domain-laag bevat geen Laravel-, database- of infrastructuurcode.

## Tests

Unit tests dekken alle code- en naaminvarianten, constructie, identiteit, statusgedrag, hernoemen, omschrijving, basisvaluta en de afwezigheid van codemutatie.
